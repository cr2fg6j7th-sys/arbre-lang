# Arbre LANG–STEFFAN

Site statique (une seule page, `index.html`) publié avec Cloudflare Pages.

- Aucune étape de build : Cloudflare publie le dossier tel quel.
- Les personnes vivantes sont masquées, les adresses des actes ne figurent pas, et les images des actes des Archives d'Alsace ne sont pas reproduites (seules les références).
- Le site n'est pas indexé par les moteurs de recherche (`robots.txt`, `_headers`).

Mise à jour : remplacer `index.html` par la nouvelle version, puis faire un commit ; Cloudflare republie automatiquement.
